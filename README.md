# VTuber 实时翻译器

把电脑上正在播放的日语直播／视频语音，实时转成中文（或你指定的语言）字幕，
以一个**置顶半透明悬浮窗**贴在屏幕底部，不挡浏览器和游戏画面。

```
系统声音(WASAPI回环) → VAD 断句 → Whisper 日语识别 → 在线翻译 → 悬浮字幕
```

- **不需要 API Key**：内置腾讯翻译君、彩云小译等国内直连通道 + 本地口语词表，默认就很快；也可填代理 / API Key 用更准的通道。
- **想更准可以随时加料**（都可留空不影响使用）：填 HTTP 代理解锁 Google/Edge，或填 DeepL / OpenAI 兼容接口（DeepSeek、通义、豆包…）的 Key。
- **不需要声卡虚拟线**，直接抓电脑播放的声音，麦克风照常可用。
- **识别在本地**，音频不出本机（只有识别出的文字会送去翻译）。

---

## 一、启动

1. 安装依赖（只需一次）：

   ```bat
   python -m pip install -r requirements.txt
   ```

   国内建议加镜像：`-i https://mirrors.aliyun.com/pypi/simple/`
   也可以直接双击 **`安装依赖.bat`**（自动带上镜像与缓存目录设置）。

2. 双击 **`启动翻译器.bat`**。
   出问题看不到报错时，改用 **`调试模式启动.bat`**（带控制台）。

3. 首次点「开始翻译」会**下载 Whisper 模型**（`small` 约 480 MB，缓存在项目内 `.runtime/hf`），之后离线可用。

## 二、使用

| 操作 | 方法 |
| --- | --- |
| 开始 / 停止 | 控制面板「开始翻译」按钮，或托盘图标右键 |
| 暂停（保留模型） | 「暂停」按钮 |
| 拖动字幕窗 | 鼠标左键拖住字幕窗任意位置 |
| 改字幕宽度 | 拖字幕窗**右下角** |
| 调字号 / 背景 / 显示原文 / 鼠标穿透 | 字幕窗**右键菜单** |
| 最小化到托盘 | 关闭控制面板窗口 |
| 鼠标穿透 | 开启后字幕不响应鼠标，打游戏不会被挡住操作（用托盘菜单切回来） |

字幕窗右键可切换「显示日语原文」，学日语时很方便。

## 三、参数怎么调

**模型选择**（控制面板 → 语音识别）

| 模型 | 显存/内存 | 速度(CPU) | 日语准确度 |
| --- | --- | --- | --- |
| tiny / base | ~1 GB | 很快 | 一般，适合低配机器 |
| **small（默认）** | ~2 GB | 快，可实时 | 较好 |
| medium | ~5 GB | 慢 2~3 倍 | 好 |
| **large-v3（最准）** | ~3 GB(int8) / 6 GB(fp16) | 慢，建议 GPU | 最好，尤其口音/外来语/嘈杂 |

- **准确度还差，先试 `large-v3`**：它对日式口语、带口音、外来语、嘈杂背景的识别明显强于 small/medium。
  在 6~8GB 显存（如笔记本 RTX 4050）上会自动改用 **int8** 运行，避免爆显存；准确度几乎不掉。
- **large-v3 嫌慢，想再快**：`large-v*` 模型**默认就已用最快档解码宽度 1**（贪心解码，最快，准确度略降但 large-v3 仍强于 small），无需再拖；
  其他模型默认 2。GPU 上还会自动把多个语音块**并行解码**（`batch_size`）进一步提速。若仍慢可换回 medium 折中。
  在面板把「解码宽度」手动拖过之后，程序会记住你的选择、不再自动降档。
- 有 NVIDIA 显卡时，把「运算」选成 `cuda`（或保持 `auto`），速度会快很多。

**纠错替换**：识别完成后做确定性替换，修掉 Whisper 把人名/梗听错的部分。
格式是「听错的写法=正确写法」，逗号分隔，例如
`うさだぺこら=兎田ぺこら,ほろらいぶ=ホロライブ`。这一项**不会**被念进字幕，
比原来的「热词提示」安全得多。

**带口音 / 日式英语（外来语）怎么处理？**

- **带口音的日语**：识别引擎开了**温度回退**（`temperature=[0.0, 0.4, 0.6]`）。口音重、
  含混、背景嘈杂时识别率明显提升；干净音频不受影响（只有真正回退时才多花一点时间）。
- **日式英语 / 和製英語**（アプデ=更新、ガチ=认真、マウント=居高临下、テンション=情绪…）：
  **不建议**走「加个英语翻译」的路子——和製英語的意思常和英语原词不同
  （マンション=公寓、パンク=爆胎），先转成英文再翻，反而多一层失真。
  翻译器在**翻译前**自动把片假名外来语替换成人工校准的中文义
  （`core/loanwords.py`，0 毫秒，比任何机翻都准）。想加词直接改那个字典即可。
- **主播真的在说英文**（整句基本是拉丁字母，如 "Thank you"）：自动改走 **EN→ZH** 路由，
  比默认 JA→ZH 准得多。这一项与上面「和製英語走中文义替换」是两套互补机制——
  一个是真英文走英文通道，一个是假名外来语直接给中文义。

**降噪预处理**：控制面板「语音识别」里可开「降噪预处理」（默认开，强度 0.5）。它在送识别前用
轻量谱减法压低**稳态**背景噪声（风扇/电流声/低频隆隆），对整体信噪比有帮助。
注意：它压不动 BGM 这类**非稳态音乐**——那需要专门的人声分离模型，更重，暂未集成。

**断句灵敏度**：
- 字幕出得太碎 → 把「停顿多久算一句」调大到 700~900 ms；
- 字幕出得太慢、半天不刷新 → 调小到 300~400 ms，或把灵敏度滑高；
- 背景音乐老是触发误识别 → 把灵敏度滑低。

## 四、常见问题

**Q：状态栏提示「音频采集失败」？**
设备下拉里换一个带 `[系统声音]` 前缀的设备，点「刷新设备」重试。
如果列表里根本没有 `[系统声音]`，说明声卡驱动没暴露回环设备，装 `pyaudiowpatch`
后重启软件即可（已在 requirements 里）。

**Q：能听到声音但不出字幕？**
先看控制面板「断句灵敏度」下面那行**实时诊断**，它直接告诉你卡在哪：

| 诊断显示 | 含义 / 怎么办 |
| --- | --- |
| `音量 x < 触发线 y` | 音量没到判定线。把「灵敏度」滑高，或调大播放器音量 |
| `音量 x > 触发线 y` | 判定正常，正在送去识别。若仍不出字，看下面两条 |
| `音量 x —— 几乎没声音` | 采集设备选错了，换一个带 `[系统声音]` 的 |

若诊断显示正常却还是没字：
- 状态栏若有「识别异常：…」→ 模型推理报错了，程序会自动回退 CPU，稍等即可；
- 状态栏若有「翻译异常：…」→ 翻译通道不通，此时仍会显示**日语原文**，
  去「翻译」里填代理或 API Key 就能出中文。

**注意**：程序启动后第一次出字幕会慢一些（要加载模型 + 确定翻译通道），
之后识别一完成字幕就先动（显示日文），译文随后补上，感知延迟通常不到 1 秒。

**Q：翻译失败 / 译文质量差？**
点「测试」按钮看哪个通道通。现状说明：

| 通道 | 国内直连 | 延迟 | 口语质量 |
| --- | --- | --- | --- |
| 腾讯翻译君 | ✅ 最快（~200ms） | ★★★★★ | ★★★ |
| 彩云小译 | ✅ 可用（~500ms） | ★★★ | ★★★★（口语/俗语最准） |
| MyMemory | ✅ 可用（有额度） | ★★☆ | ★★ |
| Edge·必应 | ⚠️ 国内不稳 | ★★★★ | ★★★★ |
| Google / DeepL | ❌ 被墙（有代理才好用） | ★★★★★ | ★★★★★ |

免费通道的默认策略：**普通句走腾讯（最快），口语化的句子自动改走彩云（最准）**，
高频口语短语还会直接命中本地词表（0 毫秒返回）。所以绝大多数情况不用填任何东西。

想要更准，任选其一（都在控制面板「翻译」区）：

1. **什么都不用填**：默认就很快了；若想口语句也快一点，把通道手动选「腾讯翻译君」；
2. **填代理**：`http://127.0.0.1:7890`（Clash/Mihomo 默认端口），或点「探测本地代理」自动找。填了之后 Google / Edge 通道立刻可用；
3. **填 Key**：选 `OpenAI 兼容接口`，填 DeepSeek 等国内大模型的 Key 与地址（`https://api.deepseek.com/v1` + `deepseek-chat`），几块钱能用很久，口语翻译最自然；
4. **填 DeepL Key**：选 `DeepL 官方 API`，免费版每月 50 万字符。

**Q：延迟大概多少？**
默认 `small` + GPU 下，识别约 0.2s、翻译约 0.2~0.5s。识别一完成字幕就先动起来（显示日文），
译文随后补上，所以**感知延迟通常不到 1 秒**；完整中英字幕一般在 0.6~1.0 秒内出现。
想要更低延迟：用 GPU / 把「最长片段」调小 / 口语多的直播可换 `medium`（更准，约 0.5s）。

**Q：想抓麦克风而不是系统声音？**
设备下拉里选带 `[麦克风]` 前缀的设备即可。

## 五、目录结构

```
Translator/
  main.py               入口（托盘 + 控制器）
  core/
    audio.py            系统声音采集（WASAPI 回环，sounddevice / pyaudiowpatch 双后端）
    vad.py              自适应能量 VAD，切分语音段
    asr.py              faster-whisper 日语识别 + 幻觉过滤 + 温度回退（抗口音）
    translator.py       腾讯翻译君 / 彩云小译 / MyMemory 等通道 + 本地口语词表，自动探测
    loanwords.py        日式英语 / 和製英語 → 中文 词典（翻译前确定性替换，0ms）
    pipeline.py         采集→识别→翻译 三线程流水线
    config.py           配置读写
  ui/
    overlay.py          悬浮字幕窗（自绘描边文字、可拖动）
    panel.py            控制面板
  .runtime/             本机运行时目录（虚拟环境/模型/缓存，不纳入 Git 仓库）
    venv/               Python 虚拟环境与所有依赖
    hf/                 Whisper 模型缓存
    pipcache/           pip 下载缓存
  config.json           运行后生成，保存你的偏好
```

> 关于 `.runtime`：Python 依赖、Whisper 模型与 pip 缓存都集中放在项目内的 `.runtime`，不占 C 盘。
> 该目录已在 `.gitignore` 中排除、**不随仓库分发**——克隆后先跑一次 `安装依赖.bat`，
> 模型会在首次识别时自动下载到 `.runtime/hf`；整个项目目录拷到别的电脑也能直接接着跑。
