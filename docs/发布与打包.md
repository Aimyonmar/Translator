# 发布与打包（v0.9.0 起）

## 一、这一版为什么发「源码包」而不是 exe

| 方案 | 体积 | 首次启动 | 维护成本 | 结论 |
| --- | --- | --- | --- | --- |
| **源码 zip + 一键脚本**（本版采用） | 约 100 KB | 装依赖 3~8 分钟 + 下模型 0.5~3 GB | 低：改代码直接发 | ✅ v0.9.0 用这个 |
| PyInstaller 单文件 exe | 400 MB ~ 1 GB | 解压慢（每次启动解到临时目录），模型仍要另下 | 高：PySide6 + CTranslate2 + onnxruntime 的隐藏依赖、杀软误报 | ⏳ 后续再评估，见 `docs/打包exe方案.md` |

关键约束：**模型与运行时不进包**。

- `.runtime`（本机 4.4 GB：venv 2.6 GB + 模型缓存 1.9 GB）全部由 `.gitignore` 排除；
- 模型首次启动时按需下载（默认 `small` 约 480 MB），之后离线可用；
- 仓库只保留纯源码（约 1.8 MB 含截图，纯净源码 < 1 MB）。

## 二、发布包内容

```
Translator-v0.9.0.zip
├─ main.py
├─ 准备模型.py                 # 首次下载模型（控制台可见进度）
├─ 安装依赖.bat                # 找 Python → 建 .runtime\venv → 装依赖
├─ 启动翻译器.bat              # 首次自动下载模型 → 启动程序
├─ 调试模式启动.bat            # 带控制台，出问题看这里
├─ requirements.txt
├─ README.md                   # 快速开始 / 设备与耳机 / 常见故障
├─ CHANGELOG.md                # 更新预告
├─ LICENSE
├─ core\*.py
└─ ui\*.py
```

**不打进包**（`.runtime/`、`config.json`、`run.log`、`__pycache__/`）：本地数据，含 API Key 与本机
路径。也**不带** `docs/`（设计文档与截图属于开发资料，留在仓库里）。

体积：源码约 **96 KB**（zip 压缩后约 40 KB），解压后 < 400 KB。

> 需要含设计文档的版本时可另出一个 `-docs.zip`，但不作为 release 主附件。

## 三、打包命令（Windows PowerShell）

在项目根目录执行，产物落在 `dist\`（已在 `.gitignore` 中）：

```powershell
$ver = "v0.9.0"
$stage = "dist\Translator-$ver"
Remove-Item -Recurse -Force $stage, "dist\Translator-$ver.zip" -ErrorAction SilentlyContinue
New-Item -ItemType Directory -Force $stage | Out-Null

# 只要源码与脚本，按白名单复制，避免把 .runtime / config.json / 日志带进去
Copy-Item main.py, 准备模型.py, 安装依赖.bat, 启动翻译器.bat, 调试模式启动.bat, `
          requirements.txt, README.md, CHANGELOG.md, LICENSE $stage
Copy-Item core, ui $stage -Recurse -Include *.py

Compress-Archive -Path "$stage\*" -DestinationPath "dist\Translator-$ver.zip"
```

打包后自检（务必做，避免把本机依赖带进包）：

```powershell
Add-Type -AssemblyName System.IO.Compression.FileSystem
$zip = [IO.Compression.ZipFile]::OpenRead("dist\Translator-$ver.zip")
$zip.Entries.Count
$zip.Entries | Where-Object { $_.FullName -match 'runtime|config\.json|\.log$|__pycache__' }
$zip.Dispose()
```

第二条命令**必须为空**。再解压到干净目录（或另一台机器）跑一遍：

1. `安装依赖.bat` → 应自动建 `.runtime\venv` 并装完；
2. `启动翻译器.bat` → 应显示模型下载进度，下完自动打开面板；
3. 面板点「开始翻译」，播放一段日语音频，确认有字幕。

## 四、Release 草稿（v0.9.0，未发布）

- **Tag**：`v0.9.0`
- **标题**：`v0.9.0 — 首个公开版本：装上即用，不需要 API Key`
- **附件**：
  - `Translator-v0.9.0.zip`（源码 + 一键脚本，必需）
  - 不含模型、不含 `.runtime`；模型首次启动自动下载
- **更新说明**：直接使用 [CHANGELOG.md](../CHANGELOG.md) 中「更新预告 · v0.9.0」一节，
  发布时整段复制到 release 正文即可，无需另写。
- **发布前检查**：
  - [ ] `git status` 干净，没有 `.runtime` / `config.json` / 日志被加入
  - [ ] 包内 `config.json` 不存在（搜索 `caiyun_token` 应为 0 命中）
  - [ ] 干净目录安装 + 首次启动跑通
  - [ ] README 的模型体积/耗时与 `准备模型.py` 的估算一致

> 本文件只是草稿；实际发布、打 tag、上传附件需人工在 GitHub 页面操作。

## 五、版本号与提交

- 版本号规则见 [CHANGELOG.md](../CHANGELOG.md) 顶部。
- 提交按主题拆，一条提交一句话说清「改了什么、对你有什么用」；
  半成品（面板分页、音频转文字、伴奏分离增强档）只写在文档的「开发中」，不写成已完成。
